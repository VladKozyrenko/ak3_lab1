# Лабораторна робота №1

## Тема

Створення програмного проєкту на мові асемблера.

## Мета

Навчитися створювати програмний проєкт на мові асемблера та користуватися відлагоджувачем.

## Використані інструменти

* Ubuntu 24.04 (WSL2)
* arm-none-eabi-gcc
* gdb-multiarch
* QEMU
* GNU Make

## Файли проєкту

* `start.S` — файл ініціалізації та таблиці векторів.
* `lscript.ld` — скрипт компонувальника.
* `Makefile` — автоматизація збірки та запуску проєкту.

## Збірка проєкту

```bash
make
```

## Запуск емулятора

```bash
make qemu
```
